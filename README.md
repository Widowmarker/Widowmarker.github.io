# Widowmaker

个人主页：个人介绍、GitHub 项目入口，以及《冰雪奇缘》主题展示。

## 本地预览

在项目目录运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

访问 http://127.0.0.1:4173/ 。直接编辑 `index.html` 即可修改页面；图片位于 `assets/`。

## GitHub Pages

发布地址：https://widowmarker.github.io/

仓库名应为 `Widowmarker.github.io`，在 Settings → Pages 中选择从 `main` 分支的根目录发布。更新网页后提交并推送，GitHub Pages 会自动发布新版本。
